## Technology notes

The ward-app prototype's committed `package.json` specifies **Expo SDK 51**, **React 18.2.0**, and **React Native 0.74.1**, along with React Navigation dependencies. Those versions describe the repository's historical state—not a current support or security assurance. The `web` script exists, but a working browser build has **not** been verified; its web-specific dependencies and compatibility need review. The app subfolder still contains the original Expo Snack starter README, which should not be read as an installation or production guarantee.

The CSN Cafe project is a coursework demonstration. Its sample pages and media should not be interpreted as an official College of Southern Nevada website, approved menus, or operational content.
